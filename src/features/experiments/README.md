# Experiments

Project-owned experiment planning, frozen runs, retained evidence, claim reviews and manually reviewed agent contributions. Canonical semantics: [Domain](../../../docs/domain.md#experiment-lab--2026-10-26); access: [Collaboration](../../../docs/collaboration.md#experiment-lab-access--2026-10-26).

The service checks membership and experiment revisions, and decodes every database result. Plan/review snapshots intentionally retain historical evidence; sources are references, not fetched files. Server Actions establish app admission and sanitized telemetry. The dedicated lab route keeps optional lab code off the ordinary questionnaire workspace. Storybook uses synthetic fixtures only.
